# Getting Started

Welcome to the AI Accelerators platform! This guide will help you get started with building and deploying AI applications.

## Overview

The AI Accelerators platform provides:
- **SDK**: Shared Python library for LLM, vector stores, and observability
- **Templates**: Pre-built application templates (RAG, agents, etc.)
- **Infrastructure**: Terraform modules for cloud deployment
